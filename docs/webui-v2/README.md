# HNC WebUI · 新版界面设计预览（v4）

`index.html` 是自包含的预览页，内置**示例数据**，不接后端。

## 设计
- **全局沿用原版 WebUI 的视觉语言**：浅灰底 + 柔光渐变背景、半透明白卡片、蓝靛渐变主色、等宽数字、渐变色柱状图、分段控件。统计页基本照原版的结构和样式做。
- **二级内容就地展开，不跳页**：设备卡片、全局操作、应用限速、流量明细、设置里的每一组（日志、配额、带宽整形、已授权设备、外观……）都是在原地展开的卡片。
- **平板（≥ 900px）**：设备页分成左侧列表 + 右侧常驻详情，设置和 DPI 页分两列。
- **内容**：补齐原版的设备过滤、全局操作、批量/模板、设备限速/延迟/抖动/丢包/封锁/白名单/重命名；应用页的追踪概览、接口切换、未匹配 SNI、导出、追踪开关；分析页的流量统计 + DPI 分析；设置页原版的全部分组。

## 动画
- **底部标签栏液态玻璃透镜**：按住标签栏时，选中块变成一颗半透明玻璃透镜，下面的图标被放大并着色；可以一直左右拖，跨过每个标签有轻微震动；松手时按弹簧物理吸附到最近的标签（带惯性、会冲过头再弹回），同时切页。拖得快时透镜会被拉长（挤压拉伸），拖出边缘有橡皮筋阻尼。
- **统一的 Q 弹曲线**：用物理弹簧（阻尼比 0.42 / 0.72）采样生成 CSS `linear()`，所有过渡共用；不支持的 WebView 自动退回 `cubic-bezier`。
- **其他**：切页按方向滑入并缩放；列表逐项浮起；卡片展开带回弹；分段控件滑块有果冻形变；开关按住会被拉长；柱状图逐根长出；数字滚动计数；主题切换用圆形扩散过渡（View Transitions）。
- 「设置 → 外观」可以关闭动画；系统开启“减少动态效果”时也会自动关闭。

## v4 改动
- 选中的胶囊按钮（如「rmnet_data0 · 移动网络」）去掉了顶部那道白色高光线。
- 主题切换的圆形扩散：关掉 View Transition 默认的交叉淡化，旧画面原样垫在下面，不再出现大片空白；另加 1.2 秒保险，任何 WebView 卡住都会自动结束。
- 底栏透镜：蓝色改成独立的一层，按下时用 0.4 秒淡出变成玻璃，图标颜色同步过渡，不再突变；透镜下面的原图标用遮罩挖掉，避免重影。
- 透镜边缘加了**色散折射**：Chromium / Android WebView 上用 Hyalite 做真折射 + 三通道色散，边缘再叠一圈红青色散描边；其他内核退回模糊 + 色散描边。

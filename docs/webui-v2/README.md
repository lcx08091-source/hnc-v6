# HNC WebUI · 新版界面设计预览

iOS 分栏风格的新版 WebUI 视觉与动画方案，参考平板适配的「列表 + 详情」布局。

- `index.html`：自包含预览页，内置**示例数据**，不接后端；不含 DPI 识别、offload 检测、能力检测等检测类功能。
- 宽度 ≥ 768px（平板、横屏）：左栏列表 + 右栏详情，选中项高亮，详情切换带滑入动画。
- 手机：列表页点进去从右侧推入详情页，支持左边缘右滑返回。
- 顶部导航栏：大标题随滚动淡出，导航栏变为毛玻璃模糊（`backdrop-filter`）。
- 动画：列表逐行浮现、标签栏指示块和分段控件弹簧滑动、按压缩放、柱状图生长、数字滚动、iOS 开关。「我的 → 外观」可切换浅色/深色/跟随系统，也可关闭动画。

# encdns_resolvers.txt — 加密 DNS(DoH / DoT / DoQ)公共解析器清单(v5.21)
#
# 用途: 「加密 DNS 策略」strict 档(bin/encdns_sync.sh)按这里的主机名与 IP 拦截,
#       dpid 的 doh_suspect 计数(src/dpid/output/encdns.go 内置同一份名单, 有测试对齐)。
# 格式: 每行一个条目, # 开头为注释, 空行忽略。
#   - 主机名(小写, 如 dns.google): 该名字及其全部子域名的明文 DNS 查询被丢弃
#     (xt_string 匹配 DNS 线格式 qname 后缀), 同时 TLS ClientHello 里 SNI 等于该名字
#     的 443 连接被 tcp-reset(xt_string 匹配 SNI 扩展里的 "|00|len16|name")。
#   - IP / CIDR(IPv4 或 IPv6): 发往它的 tcp/udp 443(DoH / DoH3)被 REJECT。
#     853(DoT / DoQ)不分目的地址, dot 档起就对所有地址拒绝。
# 注意: 只放「只提供 DNS 服务」的地址。共享 CDN 地址(如 cloudflare-dns.com 解析出的
#       104.16.x.x)不要写成 IP, 否则会误伤同 IP 上的网站 —— 那类靠 SNI/DNS 名字拦。
# 扩展: 直接加行即可; 用户自定义副本放 /data/local/hnc/etc/encdns_resolvers.txt
#       (存在时优先于模块自带的这份)。改完在界面重新保存一次策略(或等 watchdog 重同步)。
